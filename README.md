# Valence Jóias — Apresentação Executiva para Investidores

> Experiência digital imersiva e interativa desenvolvida com base no pitch deck oficial da **Valence Jóias**, combinando identidade visual de alta joalheria, fotografia conceitual e dados estratégicos de mercado.

---

## 💎 Sobre o Projeto

A **Valence Jóias** desenvolve peças em alta joalheria com design contemporâneo e manufatura de precisão na Espanha. Esta plataforma digital apresenta o modelo de negócios, expansão omnichannel, métricas de crescimento e tese de investimento.

### Principais Funcionalidades:
- **Modo Dossiê Executivo (Default):** Leitura vertical contínua, estruturada para rápida absorção por comitês de investimento e business angels.
- **Modo Apresentação (Slides):** Navegação slide-a-slide com paginação dedicada, ideal para reuniões e projeção em tela.
- **Lightbox Interativo:** Visualização em alta resolução dos ensaios fotográficos conceituais (Ensaio Museu do Ipiranga e Unboxing de Luxo).
- **Sumário Inteligente:** Acesso direto a todas as seções, adaptado para telas mobile e desktop.
- **Design System Customizado:** Tipografia editorial (Playfair Display + Montserrat), paleta Ouro Nobre e Preto Ônix, micro-interações fluidas.

## 🚀 Como Executar Localmente

1. Clone o repositório:
```bash
git clone https://github.com/orafasabino/valence-investidores.git
cd valence-investidores
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

4. Acesse no navegador:
`http://localhost:5173`

---

## 📦 Build para Produção

Para gerar os arquivos estáticos otimizados:
```bash
npm run build
```
Os arquivos prontos para deploy estarão na pasta `dist/`.
